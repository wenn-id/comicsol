# Comic Sol v2.0.0rc1

`v2.0.0rc1` is the first Native Distribution **prerelease** of Comic Sol.

## Highlights

- Portable bundled runtimes for Linux and Windows x86_64; the historical macOS archive is
  mislabeled x86_64 but contains arm64 binaries, as documented below.
- User-local installers that verify SHA-256, run `doctor`, activate transactionally, preserve prior versions for rollback, and never delete comic projects.
- Stable CLI and exact 17-tool MCP stdio surface from the same packaged deterministic engine.
- Non-root OCI image with `/data` persistence and a healthcheck.
- Per-platform unsigned metadata, CycloneDX SBOM, and `SHA256SUMS` assets.

## Install

See [`docs/install.md`](../install.md) for the current recommended native path and [`docs/install-manual.md`](../install-manual.md#verify-installer-bytes-before-first-execution) for portable extraction, historical/manual verification, rollback, and container usage.

## Verification

Before running an archive:

1. Download the platform ZIP and `SHA256SUMS` over HTTPS.
2. Calculate SHA-256 locally and compare it exactly.
3. Inspect the platform metadata and CycloneDX SBOM.
4. Verify the installer script (`install.sh`/`install.ps1`) against the signed manifest before running it — see [`docs/install-manual.md`](../install-manual.md#verify-installer-bytes-before-first-execution).
5. Run the installer, then confirm `comic-sol --version` and `comic-sol doctor`.

## Published archive correction

The macOS archive published with this release is mislabeled: `comic-sol-2.0.0rc1-macos-x86_64.zip`
contains **arm64** binaries, not x86_64 binaries. Its filename, metadata, SBOM, and
`SHA256SUMS` entry therefore describe the architecture incorrectly. Intel Macs cannot run this
archive natively. The immutable asset has not been replaced; do not use it on an Intel Mac.
From `v2.0.0rc6` onward, the macOS archive is named `macos-arm64` to match its contents.

## Known limitations

- Native artifacts are **unsigned** and are not notarized. Windows SmartScreen or macOS Gatekeeper may warn.
- Linux and Windows archives are x86_64. The historical macOS archive is labeled x86_64 but
  contains arm64 binaries; no native Intel macOS artifact was published.
- The OCI image is built and smoke-tested in CI; it is not pushed to an external registry by this release workflow.
- Live image quality depends on the image capability available to the calling agent. The package contains no provider credential or network provider SDK.

Please report installer, archive, MCP, or platform-specific failures with the platform, archive filename, checksum result, and sanitized `doctor` output.
