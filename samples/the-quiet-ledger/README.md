# The Quiet Ledger — four-page example

The largest supported scope: **four pages, eleven panels, two recurring
characters**, four distinct layouts, and one authored sound effect. Use it to see
how continuity, layout variety, and the hybrid lettering split behave across a
whole comic rather than a single page.

- Tier: **deterministic** — see [`../README.md`](../README.md) for what that proves

## Build it

From the repository root:

```bash
"$PYTHON" scripts/build_examples.py --example the-quiet-ledger
```

The result lands in `build/examples/the-quiet-ledger/` and is validated at the
`final` stage before the command reports success. It finishes as
`COMPLETE_WITH_WARNINGS`, which is expected: the artwork-dependent QA checks are
recorded as unreviewed on a placeholder raster rather than passed. See
[`../README.md`](../README.md) for the breakdown.

## What is committed here

Only the editable inputs. Panel rasters, lettered panels, composed pages, QA
records, and the PDF are generated by the build.

```text
example.json               build contract: 4 pages, 11 panels, layouts, seed
source/input.txt           the story source
source/request.json        the recorded request
plan/story-plan.json       beats and four scenes
plan/character-bible.json  Ren Calloway and Sable Orrin
plan/storyboard.json       four pages, layouts, rectangles, and authored text
prompts/panels/*.txt       one editable image prompt per panel
```

## Things worth reading in the storyboard

- **Two characters, tracked separately.** Ren and Sable each carry their own
  `visual_fingerprint.invariants`, and panels cite them by owner:
  `ren:ink-stained right index finger`, `sable:leather apron with seven numbered
  tool loops`. Sable is only cited on the pages where she actually appears.
- **Four layouts, four rectangle sets.** Each page declares a registry layout, and
  the builder re-derives the layout from the rectangles and rejects a mismatch.
- **Authored SFX takes the other half of the pipeline.** Panel `p03-03` authors the
  sound effect `TCK`. The image model is asked to draw those exact letters, and
  that panel's prompt and `negative` list say so. Pillow validates and counts the
  SFX but draws no pixels for it, so `p03-03` shows no Pillow-rendered text on the
  composed page. Compare it with the dialogue balloon on `p03-02`.
- **Text is sized per panel.** The wide `three-horizontal` panels and the 720×1120
  grid panels carry short lines; the full-page and hero panels carry the longer
  captions.
