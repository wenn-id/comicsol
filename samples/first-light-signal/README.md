# First Light Signal — one-page example

The smallest complete Comic Sol project: **one page, three panels, one character**.
Use it to see the minimum set of artifacts a finished project contains.

- Layout: `hero-top-two-bottom` — one hero panel over two supporting panels
- Text: two captions and one dialogue balloon
- Tier: **deterministic** — see [`../README.md`](../README.md) for what that proves

## Build it

From the repository root:

```bash
"$PYTHON" scripts/build_examples.py --example first-light-signal
```

The result lands in `build/examples/first-light-signal/` and is validated at the
`final` stage before the command reports success.

## What is committed here

Only the editable inputs. Panel rasters, lettered panels, the composed page, QA
records, and the PDF are generated by the build.

```text
example.json               build contract: 1 page, 3 panels, seed
source/input.txt           the story source
source/request.json        the recorded request
plan/story-plan.json       logline, theme, beats, and two scenes
plan/character-bible.json  Ada Vantor's visual fingerprint and invariants
plan/storyboard.json       the page, its layout, panel rectangles, and authored text
prompts/panels/*.txt       one editable image prompt per panel
```

## Things worth reading in the storyboard

- **Panel rectangles are exact.** `p01-01` is the 1472×1176 hero; `p01-02` and
  `p01-03` are the 720×1064 pair below it. These are the registry rectangles for
  `hero-top-two-bottom` on a 1600×2400 page with a 64 px margin and 32 px gutters.
- **Text is sized to its panel.** The hero panel carries a full caption sentence.
  The 720×1064 panel holds a four-word line, because a panel that size fits roughly
  fourteen words and lettering fails closed rather than printing over artwork.
- **Continuity entries name their owner.** `ada:copper headset band worn above the
  ears` is checkable against Ada's `visual_fingerprint.invariants`;
  `relay-mast:fog-bleached steel lattice...` is checkable against that scene's
  `continuity_anchor`.
- **Every panel forbids text.** Lettering is applied downstream by Pillow, so the
  generated artwork must contain no balloons, captions, signatures, or watermarks.
