# Comic Sol Privacy Policy

**Last updated:** 2026-08-13

Comic Sol is a local-first Codex plugin published by Alwan Juliawan (`wenn-id`).
This policy describes the plugin bundle at
[github.com/wenn-id/comicsol](https://github.com/wenn-id/comicsol).

## Data handled by the plugin

- Comic Sol has no hosted backend, account system, analytics, advertising, or
  database.
- Project files, prompts, generated images, PDFs, logs, and QA artifacts are
  written to the local project/output directory selected by the user.
- The plugin does not intentionally collect names, email addresses, payment
  data, credentials, API keys, or device identifiers.
- The Codex host may process prompts and local files according to the user's
  Codex/OpenAI account and product settings.
- When the active agent uses an image-generation capability, the story and
  visual facts needed for that request may be sent to that capability's
  provider. Provider retention and processing are governed by that provider's
  terms and privacy policy. Comic Sol does not promise provider-side deletion.

## What Comic Sol does not do

Comic Sol does not upload project files to a Comic Sol server, sell personal
information, or add telemetry. It does not ask users to put secrets in prompts,
project manifests, or logs. Users remain responsible for reviewing the active
Codex host, image provider, MCP server, and operating-system permissions.

## Retention and deletion

Local artifacts remain until the user deletes them. The plugin has no separate
remote storage to delete. Remove generated project directories and any Codex or
provider-side artifacts through those products' own controls.

## Contact

For support or privacy questions, open an issue at
[github.com/wenn-id/comicsol/issues](https://github.com/wenn-id/comicsol/issues).
Do not include secrets, private source text, or personal data in a public issue.

## Changes

This policy may change when the plugin architecture changes. The date above
identifies the current version of this document.
