# Safety, privacy, and IP

## Local artifacts and external prompts

Keep all source, plans, prompts, attempts, panels, pages, PDF, manifest, logs, and QA report
inside the user-selected project directory. Send an image capability only the minimum
story and visual facts needed for the current image—never unrelated source text or
absolute local paths.

Before external generation, warn and ask for redaction when input appears to contain a
secret, credential, private key, financial account number, or highly specific personal
contact data. Detection is best effort. Logs contain only event names, relative paths,
hashes, attempt counts, and sanitized categories; never secrets, raw provider responses,
or full tool arguments. Disclose that external capability policies govern transmitted
prompts/references and do not promise provider-side deletion.

## Originality and rights

- Default to original descriptive direction: line, contrast, palette, lens, light,
  texture, and era-neutral genre language.
- If asked for a living artist, active studio, or named franchise style, decline direct
  imitation and translate the request into non-identifying visual characteristics. Omit
  protected names from generation prompts.
- Treat user-provided copyrighted text as user-authorized input without claiming rights,
  licensing, commercial clearance, copyrightability, or freedom from provider terms.
- Generate no false attribution, logo, signature, or watermark.

## People, minors, and refusals

- Depictions of real people require a user-supplied authorized reference and remain
  subject to the selected capability's policy; face swapping is out of scope.
- Refuse sexual content involving minors or ambiguous-age young characters.
- Refuse non-consensual explicit sexual content and graphic real-world wrongdoing
  instructions. Teen-rated fictional action and non-graphic injury remain in scope.
- Treat the image capability's refusal as authoritative. Do not retry with euphemisms,
  prompt obfuscation, alternate providers, or any other evasion. Preserve work, record a
  sanitized refusal category, transition to `BLOCKED`, and explain safe resume options.
